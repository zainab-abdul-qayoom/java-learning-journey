# Object Oriented Programming in Java (IBM)
📍 Course: Coursera - Object Oriented Programming in Java
Part of the IBM Java Developer Professional Certificate.

## What This Covers
- OOP fundamentals: classes, objects, properties, methods
- Encapsulation & Java constructors
- Inheritance, Polymorphism, Abstraction, Inner Classes
- Java Collections Framework: Lists, Sets, Queues, Maps
- File handling: byte streams, input/output streams, directories
- Date and Time handling: formatting, time zones, parsing
- Final project + certificate exam
