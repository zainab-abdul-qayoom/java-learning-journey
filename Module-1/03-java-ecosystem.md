# Video: The Java Ecosystem — Remember This

## Core Components
- **JDK** = toolkit for developers → contains Compiler (javac) + JRE + utilities
- **JRE** = runs Java apps → contains JVM + core libraries
- **JVM** = executes bytecode, gives platform independence

## IDEs (write code easily)
- Eclipse, IntelliJ IDEA, NetBeans

## Frameworks (reuse code, faster dev)
- **Spring** — enterprise apps (DI, AOP, MVC)
- **Spring Boot** — simplified Spring setup
- **Hibernate** — ORM (maps Java objects ↔ database tables)

## Build Tools
- **Maven** — dependency management
- **Gradle** — incremental builds, uses Groovy/Kotlin

## Servers
- **Apache Tomcat** — small/medium web apps
- **JBoss** — large enterprise apps

## Testing
- **JUnit** — basic testing
- **TestNG** — advanced (parallel, data-driven)

## Other Uses
- **JavaFX / Swing** — desktop apps
- **Android SDK + Android Studio** — mobile apps (Java still used, Kotlin preferred now)
- **Java ME / Embedded Java** — for small devices/sensors

---

## 🧠 Extra — What matters most as a developer
- Don't try to memorize everything here — **just recognize the names**. You'll actually use Maven/Gradle, Spring, JUnit later when building real projects.
- **Most important for jobs:** Spring Boot + Hibernate + Maven/Gradle + JUnit — this combo is the real "Java backend developer" stack.
- **JDK vs JRE vs JVM** is a guaranteed interview question:
  - JDK = for developers (write + compile code)
  - JRE = for users (run code)
  - JVM = the engine inside both that actually runs the bytecode
