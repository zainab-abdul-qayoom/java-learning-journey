# Video: Using Key Java Features — Remember This

## OOP Basics (very important — asked in almost every interview)
- **Class** = blueprint (e.g. "Car" — defines color, speed, model)
- **Object** = actual thing made from class (e.g. "red Toyota Corolla")
- **Inheritance** — one class gets features from another (Car inherits from Vehicle)
- **Polymorphism** — same action, different behavior (start() works differently for car vs boat)
- **Encapsulation** — hides sensitive data, only accessible safely (private engine number)

## Other Key Java Features
- **Platform independence** — JVM lets code run on any OS without change
- **Strongly typed** — must declare data type (int, String, etc.) → catches errors early
- **Automatic memory management** — garbage collection cleans unused memory automatically
- **Multithreading** — multiple tasks run at once (e.g. banking app: input + transaction processing together)
- **Standard library** — built-in tools for networking, files, data handling
- **Security** — bytecode verification + security manager checks permissions

## Where Used
- Web (Spring), Mobile (Android), Enterprise apps

## Trends (just recognize these, don't memorize deeply)
- Cloud-native/microservices — Spring Boot, Quarkus
- Serverless — AWS Lambda, Google Cloud Functions
- AI/ML — DeepLearning4J, DJL

---

## 🧠 Extra — What matters most
- The **4 OOP pillars** (Inheritance, Polymorphism, Encapsulation + Abstraction, which comes later) are THE most asked Java interview topic. Learn these 4 words cold — you'll build on them heavily in your next course (OOP).
- "Strongly typed" is why Java feels stricter than Python/JS — this is actually a strength, not annoyance, in large projects.
- You don't need to explain multithreading deeply yet — just know it means "doing multiple things at once."
