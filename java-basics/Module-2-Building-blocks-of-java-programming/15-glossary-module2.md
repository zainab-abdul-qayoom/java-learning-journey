# Glossary: Building Blocks of Java Programming — Remember This

*(Condensed + grouped — full official glossary has more, but these matter most.)*

## String Methods (very commonly used — practice these)
- `.length()` — length of string
- `.charAt(index)` — get character at position
- `.equals()` — compare two strings/objects for equality
- `.substring(start, end)` — extract part of a string
- `.replace()` — replace part of a string
- `.split()` — break string into array using a delimiter
- `.toUpperCase()` / `.toLowerCase()` — change case

## Useful Built-in Classes
- **Scanner** — take user input (`nextInt()`, `nextLine()`)
- **Math** — math functions (sqrt, pow, abs)
- **Random** — generate random numbers
- **ArrayList** — resizable list (better than array when size changes)

## Type Conversion
- `parseInt()` — string → int
- `parseDouble()` — string → double

## OOP Basics (repeats — important!)
- **Class / Object / Constructor** — blueprint / instance / initializer
- **Inheritance** — `extends` keyword, child gets parent's features
- **Interface** — `implements` keyword, defines methods a class must have
- **Polymorphism** — same method behaves differently (overloading + overriding)
- **Overloading** — same method name, different parameters
- **Override** — subclass redefines parent's method
- **Encapsulation / Abstraction** — hide details, expose only what's needed
- **this** — refers to current object
- **super** — refers to parent class

## Access Modifiers
- **public** — accessible from anywhere
- **private** — accessible only within same class

## Loops & Control
- `for`, `while`, `do-while` — repeat code
- `break` — exit loop
- `continue` — skip to next iteration

## Exceptions (repeats — Module 4 will go deep)
- **try/catch block** — handle errors
- **throw** — manually raise an exception
- **throws** — declares a method might throw an exception
- **Checked vs Unchecked exception** — must-handle vs optional-handle

## Misc Useful Terms
- **static method/variable** — belongs to class, not object
- **null** — means "no value"
- **Object instantiation** — creating an object using `new`
- **Method signature** — method name + parameter list (defines uniqueness)

---

## 🧠 Extra — What matters most
- **String methods + Scanner + ArrayList** are the ones you'll actually type in code every day — practice these first.
- **this vs super** is a common small interview question: `this` = current object, `super` = parent class.
- Don't stress memorizing rare terms like `Folder structure for packages` — just know String methods, OOP terms, and loops cold.
