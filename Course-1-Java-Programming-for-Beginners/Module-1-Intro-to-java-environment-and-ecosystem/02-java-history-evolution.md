# Video: Introduction to Java — History and Evolution — Remember This

## Basics
- Java = write once, run anywhere (WORA) — runs on any device without change
- Used in: web apps, mobile apps, enterprise software

## History (quick timeline)
- 1991 — Started as "Oak" by James Gosling (Sun Microsystems)
- 1995 — Renamed **Java**
- 1998 — Java 2 (Swing, Collections Framework)
- 1999 — J2EE (for enterprise apps)
- 2006 — Became **open source**
- 2010 — **Oracle** acquired Sun Microsystems (now owns Java)

## Key Versions (interview favorite)
- **Java 5 (2004)** — Generics, Annotations, Enhanced for-loop
- **Java 8 (2014)** — Lambda expressions, Stream API, new Date/Time API
- **Java 11 (2018, LTS)** — HTTP Client API, better garbage collector
- **Java 17 (2021, LTS)** — Pattern matching, Sealed classes
- **Java 23 (2023)** — Record patterns, Virtual Threads, Foreign Function API

## Why Java Matters
- Platform independent because of **JVM** (runs Java bytecode)
- Backward compatible — old code runs on new Java versions
- Big companies use it (LinkedIn, eBay)

## 🧠 Extra — Things I think you should know as a developer
- **LTS (Long Term Support)** versions = the ones companies actually use in real jobs (Java 8, 11, 17, 21). Learn on these, not experimental new versions.
- Most real jobs today use **Java 8 or Java 17** — so don't worry about memorizing every version, just know the big jumps (8 → 11 → 17).
- **JVM vs JDK vs JRE** confusion is a very common interview question — make sure your next video note on this is solid.
- As you go into OOP next, focus on **4 pillars**: Encapsulation, Inheritance, Polymorphism, Abstraction — these get asked in almost every interview.
